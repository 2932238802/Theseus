# 第三方账号绑定与 GitHub 登录设计方案

> 日期：2026-11-01
> 状态：v1 已实现
> 关联：`2610272_个人界面的完善.md`、`2611014_安全与限流收口设计方案.md`、`2610303_审计中心设计方案.md`、`backend_api.md`

## 1. 背景

账号目前只有用户名/邮箱 + 密码一种登录方式。校园用户通常已有 GitHub 账号，反复输入密码体验较差；同时如果开放第三方自动建号，未经学校验证的第三方邮箱可能被用来抢注或冒充。本期先做风险最低的形态：

- 已有账号可在账号设置中绑定 GitHub
- 绑定后可用 GitHub 快捷登录
- 不通过 GitHub 自动创建 Theseus 账号

## 2. 目标与非目标

### 2.1 目标

- 支持 GitHub OAuth 2.0 授权，`read:user` 最小权限
- 绑定关系落库，同一第三方账号只能绑定一个用户，同一用户每个平台最多一条
- 登录只对已绑定账号生效，未绑定返回明确提示
- 不把 JWT 放进跳转 URL，使用 2 分钟一次性票据换取 JWT
- 未配置凭据时自动关闭入口，不影响现有账号密码登录
- 绑定、解绑与第三方登录写审计

### 2.2 非目标

- Google、Gitee 等其它平台
- 第三方邮箱自动注册、自动合并同名账号
- 第三方账号作为唯一登录方式（Theseus 密码始终保留）
- 多账号切换、组织级 SSO

## 3. 数据模型

新增迁移 `0041_oauth_identities.sql`：

```sql
CREATE TABLE oauth_identities (
    id BIGSERIAL PRIMARY KEY,
    user_id INTEGER NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    provider VARCHAR(20) NOT NULL,
    subject VARCHAR(100) NOT NULL,
    login_name VARCHAR(255) NOT NULL,
    display_name VARCHAR(255),
    email VARCHAR(255),
    created_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,
    last_login_at TIMESTAMPTZ,
    UNIQUE (provider, subject),
    UNIQUE (user_id, provider)
);
```

- `subject` 存 GitHub 返回的数字 id，不使用可变的登录名
- `UNIQUE(provider, subject)` 防止两个 Theseus 账号绑同一个 GitHub
- `UNIQUE(user_id, provider)` 让每个用户的 GitHub 绑定最多一条，重新绑定会覆盖旧记录
- 用户注销时级联删除绑定
- 同一迁移把 `auth_tokens.purpose` 白名单扩展 `oauth_login`，登录票据复用现有一次性令牌表

## 4. 配置

只改 `.env`，不修改服务器代码：

| 变量 | 说明 |
|---|---|
| `OAUTH_GITHUB_CLIENT_ID` | GitHub OAuth App 的 Client ID |
| `OAUTH_GITHUB_CLIENT_SECRET` | Client Secret |
| `OAUTH_CALLBACK_BASE` | 回调公开地址，默认等于 `FRONTEND_BASE_URL` |

GitHub OAuth App 的 Authorization callback URL 填：

```text
{OAUTH_CALLBACK_BASE}/api/auth/oauth/github/callback
```

开发环境 `OAUTH_CALLBACK_BASE=http://localhost:5173`，Vite 会把 `/api` 代理到后端；生产环境由 Nginx 反代 `/api`。

两个凭据必须同时配置或同时留空，只配置一个时后端启动失败。

## 5. 流程

### 5.1 绑定

1. 用户登录后进入账号设置 → 第三方账号
2. 前端调用 `POST /api/auth/oauth/github/start`，`mode=bind`
3. 后端签发 10 分钟有效的签名 `state`，跳转 GitHub
4. 回调校验 `state`，用授权码换取 access token，读取 GitHub 用户 id
5. 检查该 GitHub 是否已绑定其他用户；已绑定返回 `oauth=taken`
6. 写入或更新绑定，记录审计，重定向 `/profile?settings=account&oauth=bound`

### 5.2 登录

1. 登录页显示已配置平台的按钮
2. `POST /api/auth/oauth/github/start`，`mode=login`
3. 回调按 `provider + subject` 查找绑定
4. 未绑定重定向 `/login?oauth=unbound`，账号不可用重定向 `/login?oauth=disabled`
5. 已绑定则更新 `last_login_at`，签发一次性票据，重定向 `/oauth/callback?code=...`
6. 前端调用 `POST /api/auth/oauth/exchange` 换取 JWT 并写入本地会话

### 5.3 解绑

1. 账号设置中填写当前密码并确认
2. `DELETE /api/auth/oauth/github` 校验密码后删除绑定
3. 写 `auth.oauth_unbind` 审计

## 6. 接口

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| GET | `/api/auth/oauth/providers` | 无 | 平台与启用状态 |
| POST | `/api/auth/oauth/github/start` | `bind` 需登录 | 返回授权地址 |
| GET | `/api/auth/oauth/github/callback` | 无 | 回调后重定向前端 |
| POST | `/api/auth/oauth/exchange` | 无 | 一次性票据换 JWT |
| GET | `/api/auth/oauth/bindings` | 用户 | 当前账号绑定列表 |
| DELETE | `/api/auth/oauth/github` | 用户 | 密码确认后解绑 |

## 7. 安全与边界

- `state` 是 HS256 签名的 JWT，包含 `mode`、`uid` 与 10 分钟过期时间，绑定用户来自签名内容而不是客户端参数
- 登录票据复用 `auth_tokens`，2 分钟过期、一次使用，消费后立即失效
- 回跳前端的 `redirect` 只接受 `/` 开头的同源路径，拒绝 `//host` 与反斜杠
- 解绑必须验证密码，避免会话被盗后直接解除绑定
- 未配置凭据时 `start` 返回 403，前端不渲染按钮
- GitHub 仅请求 `read:user`，不读取仓库与组织数据
- 限流：发起 30 次/10 分钟/IP，回调 60 次/10 分钟/IP，兑换 30 次/10 分钟/IP，解绑 10 次/小时/用户

| 场景 | 处理 |
|---|---|
| GitHub 账号已绑定其他用户 | 重定向 `oauth=taken` |
| GitHub 账号未绑定 | 重定向 `oauth=unbound` |
| 用户在 GitHub 拒绝授权 | 重定向 `oauth=denied` |
| `state` 过期或被篡改 | 重定向 `oauth=error` |
| 绑定模式未登录 | 401 |
| 解绑密码错误 | 403「密码不正确」 |
| 解绑未绑定平台 | 404 |
| 凭据只配置一半 | 后端启动失败并提示必须同时配置 |

## 8. 前端

- `LoginAndRegisterPage.vue`：读取 `providers`，仅显示已启用的平台按钮；根据 `oauth` 查询参数展示未绑定、已取消、失败提示
- `OAuthCallbackPage.vue`：`/oauth/callback` 消费票据，写入会话后跳回原路径
- `AccountSettingsDialog.vue`：新增「第三方账号」分区，展示绑定信息、绑定按钮与解绑密码确认
- 绑定成功回调到 `/profile?settings=account&oauth=bound`，个人页自动打开账号设置并停留在第三方账号分区
- 设置中心账号说明补充第三方账号入口

## 9. 验证

- `cargo fmt --all --check`
- `cargo clippy --all-targets -- -D warnings`
- `cargo test --all-targets`：包含同源回跳白名单单元测试
- `npm run build`
- 手工验证（需要真实 GitHub OAuth App）：
  - 未配置凭据时登录页无按钮，直接调用 `start` 返回 403
  - 绑定后账号设置显示 GitHub 登录名与绑定时间
  - 退出后用 GitHub 登录成功，票据 2 分钟后失效
  - 同一 GitHub 绑定第二个账号返回 `oauth=taken`
  - 解绑密码错误被拒绝，正确后按钮恢复为「绑定 GitHub」
  - 审计中心出现 `auth.oauth_bind` / `auth.oauth_unbind` / `auth.oauth_login`
