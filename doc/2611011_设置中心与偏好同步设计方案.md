# 设置中心与跨设备偏好同步设计方案

> 日期：2026-11-01
> 状态：v1 已实现
> 关联：`2610272_个人界面的完善.md`、`2610260_快捷键方案.md`、`2610316_语义补全设计方案.md`、`backend_api.md`

## 1. 目标

把散落在 `localStorage` 的个性化选项收拢到统一设置中心，并在登录后同步到账号：

- 新增 `/settings` 页面，集中管理外观、编辑器、题目默认值与快捷键
- 登录用户修改后自动保存到服务端，换设备登录后恢复
- 未登录或网络异常时继续使用本机设置，不影响正常答题
- 服务端只接受白名单内的键和合法取值，不保存任意 JSON
- 旧的 `localStorage` 设置首次登录时自动迁移，不丢已有偏好

## 2. 数据模型

`0038_user_preferences.sql` 新增 `user_preferences`：

| 字段 | 说明 |
|---|---|
| `user_id` | 用户，指向 `users(id)`，删除用户时级联删除 |
| `key` | 偏好键，服务端白名单校验 |
| `value` | JSONB，键对应的值 |
| `updated_at` | 最后更新时间，写入时刷新 |
| 主键 | `(user_id, key)` |

键与取值范围：

| 键 | 类型 | 取值 |
|---|---|---|
| `appearance.theme` | string | `light` / `dark` / `system` |
| `editor.theme` | string | `system` 或 `src/utils/monacoTheme.ts` 中的主题名 |
| `editor.font_size` | int | 12–20 |
| `editor.tab_size` | string / int | `auto` / 2 / 4 / 8 |
| `editor.completion` | bool | 是否默认开启语义补全 |
| `problems.language` | string | `cpp` / `java` / `python` / `javascript` |
| `problems.page_size` | int | 20 / 50 / 100 |
| `shortcuts.bindings` | object | 动作 id 到按键字符串或 `null`，最多 64 项 |

## 3. 接口

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| GET | `/api/profile/preferences` | 登录用户 | 返回 `{preferences:{key:value}}` |
| PUT | `/api/profile/preferences` | 登录用户 | 请求 `{"preferences":{key:value}}`，批量写入并返回完整偏好 |
| DELETE | `/api/profile/preferences` | 登录用户 | 清空当前用户全部偏好 |
| DELETE | `/api/profile/preferences/{key}` | 登录用户 | 删除单项，键必须在白名单内 |

约束：

- 每次最多提交 64 项，未知键返回 400「不支持的偏好项」
- 值的类型或范围不合法时返回 400「偏好项格式不正确」
- 快捷键绑定只校验结构与长度，具体冲突与浏览器占用仍由前端快捷键规则处理
- 所有接口只操作当前登录用户的数据

## 4. 前端实现

| 文件 | 变更 |
|---|---|
| `src/store/preferences.ts` | 偏好状态、默认值、本机镜像、350ms 防抖同步、首次登录迁移与退出重置 |
| `src/api/preferences.ts` | 偏好读写与删除请求 |
| `src/types/preference.ts` | 缩进宽度类型 |
| `src/views/SettingsPage.vue` | 外观、编辑器、题目、快捷键与账号五个分区，支持恢复默认 |
| `src/styles/settings.css` | 设置页卡片、行、开关与响应式布局 |
| `src/store/shortcuts.ts` | 新增 `applyOverrides` 与变更回调，快捷键修改自动同步 |
| `src/components/CodeEditor.vue` | 新增 `tabSize` 属性，`auto` 时保持 Python 4 空格、其余 2 空格 |
| `src/views/OjPage.vue` | 语言、字号、编辑器主题与补全状态接入偏好 store |
| `src/views/ProblemsPage.vue` | 每页题数接入偏好 store |
| `src/components/NavBar.vue` | 主题切换改为写入偏好，个人菜单新增「个人偏好设置」 |
| `src/App.vue`、`src/router/index.ts` | 登录后拉取偏好，新增 `/settings` 路由 |

同步规则：

- 页面加载时先用 `localStorage` 初始化，保证未登录也能立即使用
- 登录后拉取服务端偏好并覆盖本机值，同时回写 `localStorage`
- 首次登录时，服务端没有的旧本机偏好会批量上传一次，完成迁移
- 每次修改先更新界面并写本机，再以 350ms 防抖提交服务端；请求期间的新修改不会被旧响应覆盖
- 退出登录后丢弃服务端状态，回到本机设置
- 设备相关状态不进入账号偏好：题目与编辑器分栏宽度、结果面板高度、各语言草稿仍只保存在本机
