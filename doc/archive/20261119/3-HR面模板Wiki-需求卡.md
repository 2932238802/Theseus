## CR-003 HR 面模板 Wiki，管理员增删改查

- **类型**：功能新增
- **问题与价值**：HR 面问题重复度高，求职者需要可复用的模板与套路，而不是一篇篇面经。做成管理员维护的 Wiki 后，左侧栏目、右侧正文都可更新；Markdown 正文支持加粗等基础格式，维护成本低。
- **目标用户与场景**：
  - 读者：在面经板块选择「HR 面」后看到模板入口，进入后按左侧栏目阅读模板与套路
  - 管理员：在后台新增、编辑、删除模板页，拖拽调整左侧顺序
  - 非 HR 场景：模板入口不出现，避免技术面读者被无关内容打扰
- **成功指标**：
  - 管理员可完成模板页的增删改查，保存后读者端立即可见
  - 左侧顺序可拖拽调整，刷新后保持
  - 正文支持 Markdown 基础语法与 `Ctrl+B` / `Ctrl+I` 等快捷键
  - 读者只有在选择「HR 面」后才会看到模板入口
- **范围**：
  - 数据：新增 `interview_templates` 表（标题、正文、排序、创建/更新人、时间）
  - 接口：读者端列表/详情；管理员端新增、修改、删除、排序
  - 前端读者端：HR 面模板页，扁平左侧列表 + 右侧 Markdown 正文
  - 前端管理端：模板列表、Markdown 编辑器（工具栏、快捷键、预览）、拖拽排序
  - 权限：读沿用面经板块的 Plus 权限；写仅管理员
- **不在范围内**：
  - 不显示 VIP / Plus 升级字样（用户明确要求）
  - 不做两级分组（用户已选扁平列表）
  - 不做版本历史、协同编辑、评论
  - 不做模板使用统计
  - 不做草稿 / 发布状态（保存即生效）
  - 不把模板混入普通面经列表
- **NFR**：
  - 性能：适用，模板页数据量小，按需加载
  - 安全：适用，Markdown 渲染沿用现有清洗；管理端写接口鉴权；防 XSS
  - 隐私：不适用
  - 兼容：适用，新增页面不影响现有面经列表与详情
  - 可观测：适用，模板新增/修改/删除/排序写审计日志
  - 成本：不适用
- **约束与依赖**：
  - 读者端入口依赖 CR-002 的「HR 面」类型
  - Markdown 渲染复用 `MarkdownBody.vue` 与现有清洗链路
  - 编辑器在现有发帖「编辑 / 预览」模式上增加工具栏与快捷键
- **风险与未知**：
  - 编辑器测试面较大（快捷键、选区、粘贴、预览、XSS）
  - 管理员误删模板页，需要二次确认
  - 排序在多人同时编辑时可能互相覆盖，需要简单冲突提示
- **选项**：
  - **A. 做（用户已选）**：扁平栏目 + Markdown 编辑器（工具栏 / 快捷键 / 预览）+ 管理员 CRUD + 拖拽排序
  - **B. 拆小**：先做单层栏目与纯 Markdown 编辑，工具栏后续补
  - **C. 先 spike**：验证编辑器选型与 Markdown 清洗
  - **D. 缓办**
  - **E. 不做**
- **用户选择（2026-11-19）**：扁平左侧列表；拖拽排序；Markdown 源码 + 工具栏 + 快捷键 + 预览；保存即生效
- **待确认决策**：
  - 读者端路由：`/forum/interview/templates` 还是独立 `/interview/templates`
  - 编辑器工具栏具体项（加粗、斜体、标题、列表、引用、代码、链接、预览）
  - 是否需要"插入模板片段"（如 STAR 四步）快捷按钮
- **关联需求/任务**：R-003 / T-004、T-005、T-006（G1 回填）
- **状态**：已确认（G0）
