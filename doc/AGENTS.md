- 自动判题分、教师单题手动分/评语、整体评语、批改台、截止后发布成绩。
- 作业策略：迟交宽限与扣分、每题提交次数、三种计分策略、成绩可见时机、补交/免修、解析独立发布、匿名统计、他人 AC 代码与策略审计。

## 维护规则

1. 功能完成后，同时更新 `总体设计.md` 的「一页结论」「现状盘点」「实施路线」「里程碑」以及本文件的进度快照。
2. 设计目标与当前实现不一致时，在对应设计章节增加「当前实现」说明，不要把未实现项写成已完成。
3. 更新状态前先核对代码：后端路由、数据库迁移、前端路由/页面、冒烟脚本至少检查一项实际证据。
4. 文档只记录可验证事实；不写入 token、密码、数据库连接串、真实用户隐私或隐藏用例内容。
5. 新增文档沿用 `YYMMDDNN_主题.md` 命名，并补充到「文档地图」；临时空文件不要提交。
6. 每次同步进度时更新 `总体设计.md` 顶部日期与实现基线提交，避免继续出现“已完成”和“当前缺口：无”并存。
7. 界面文案不使用中文句号「。」；需要表达多个意思时分行书写。Agent 新增或修改前端文案时同样遵守。
