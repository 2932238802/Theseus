## 当前进度快照

> 与 `总体设计.md` 同步；状态只用以下三种表述：**已完成**、**部分完成**、**未开始**。

**已完成**

- 三角色互斥权限：`student` / `teacher` / `admin`，认证每次从数据库读取角色。
- 题库、运行、提交判题、隐藏用例、提交记录与排行榜。
- 组织创建/归档、邀请码、学生邀请、成员管理、退出/移除。
- 作业草稿/组题/开始与截止时间/发布/归档；学生作业提交与截止校验。
- 自动判题分、教师单题手动分/评语、整体评语、批改台、截止后发布成绩。
- 作业策略：迟交宽限与扣分、每题提交次数、三种计分策略、成绩可见时机、补交/免修、解析独立发布、匿名统计、他人 AC 代码与策略审计。
- 个人中心：仪表盘、用户名/邮箱/密码修改、邮箱验证换绑、退出所有设备、注销匿名化、头像上传、近 30 天学习分析、论坛收藏、跟随系统主题。
- 个人菜单「我的作业」：按组织汇总学生/教师可见作业，未加入组织时置灰不可点击；复用 `/api/classes` 与 `/api/classes/{id}/assignments`，无新增后端接口。
- 首页学习工作台：继续学习、学习概览、快捷入口、最近活动、随机一题，数据来自 `/api/home/overview`；答题草稿按用户+题目+语言同步到 `problem_drafts`，支持跨设备继续编辑。
- 作业发布与成绩发布站内通知；管理员按用户/角色/全站发送通知。
- 教师出题、管理员题目审核、用户与角色管理、论坛管理端。
- 邮箱验证、密码找回、一次性令牌与 outbox 投递。
- 竞赛：4 人实时匹配、段位分、比赛页/结果页、提前离场、结算与结果通知、摄像头与屏幕共享强制授权、切屏/粘贴事件记录、疑似粘贴按管理员负载分配与人工复核；确认作弊固定扣 25 信誉分、取消本场成绩、已结束比赛重新排名并按差额修正段位分；信誉分低于 40 禁止排位/赛事/论坛，低于 0 自动封号并加入邮箱黑名单，管理员可定量恢复；每日签到 +0.1 信誉分。竞赛首页限时赛事列表、全部赛事页、独立赛事详情、关注与历史回看；公开/邀请/外部链接报名、名额上限、组织范围、报名截止；管理端赛事与规则/题目配置；赛事内答题、赛事排行榜、排位榜；匹配 3 分钟/5 分钟降级；赛事同步校园墙并自动取消置顶。
- 竞赛断线重连：比赛页每 10 秒心跳，30 秒无心跳标记 `disconnected`，距最后一次心跳 120 秒变为 `timed_out` 并冻结成绩；排位赛全员断线取消且不改变段位分，赛事比赛不取消；无人可提交时提前结算；刷新、切标签页与短时断网后自动恢复；站内信覆盖断线超时与比赛取消。
- 实时推送：新增 `POST /api/ws/ticket` 一次性票据与 `GET /api/ws`；服务端按用户广播 `notification.new` 与 `match.found`，通知在提交后约 2 秒推送；前端单例连接、指数退避重连，轮询与 REST 快照保留为兜底。
- 防作弊 M2：判题成功后异步扫描同作业/同题/同语言提交，token 归一化 + winnowing 指纹生成 `similarity_pairs`；超阈值生成教师复核报告；教师可确认/排除并可选将该题判 0 分；学生可申诉一次，由报告处理人裁定，撤销时按快照恢复成绩；新增教师「作弊复核」与学生「我的申诉」页面。
- 冒烟脚本：`smoke_teaching.sh`、`smoke_submission.sh`、`smoke_forum.sh`、`smoke_problem_review.sh`、`smoke_auth_email.sh`、`smoke_contest_events.sh`、`smoke_notifications.sh`、`smoke_realtime.sh`、`smoke_anticheat.sh`。

## 维护规则

1. 功能完成后，同时更新 `总体设计.md` 的「一页结论」「现状盘点」「实施路线」「里程碑」以及本文件的进度快照。
2. 设计目标与当前实现不一致时，在对应设计章节增加「当前实现」说明，不要把未实现项写成已完成。
3. 更新状态前先核对代码：后端路由、数据库迁移、前端路由/页面、冒烟脚本至少检查一项实际证据。
4. 文档只记录可验证事实；不写入 token、密码、数据库连接串、真实用户隐私或隐藏用例内容。
5. 新增文档沿用 `YYMMDDNN_主题.md` 命名，并补充到「文档地图」；临时空文件不要提交。
6. 每次同步进度时更新 `总体设计.md` 顶部日期与实现基线提交，避免继续出现“已完成”和“当前缺口：无”并存。
