### 2. 把模糊需求转换成可执行过程

这是二面的重点
面试官想听的不是「我做了什么」，而是「你怎么把不清楚的事情变清楚」

可以按下面的顺序讲

```text
背景
→ 需求哪里模糊
→ 你向谁确认了什么
→ 怎么拆成阶段
→ 每阶段的产出和验收标准
→ 怎么控制风险
→ 最终结果
```

**拆解框架**

1. 明确目标
   业务要解决什么问题，成功指标是什么
2. 划清边界
   哪些做，哪些不做，依赖谁
3. 拆解任务
   按用户流程或数据流拆成可独立交付的模块
4. 定义接口
   输入、输出、异常和状态
5. 排优先级
   先做能验证核心假设的部分
6. 设置里程碑
   每个阶段有可演示或可度量的结果
7. 验证与回滚
   灰度、日志、监控、失败预案

**表达上的注意**

- 不要把所有事情说成自己一个人做的
  讲清楚你负责的边界和协作方式
- 模糊需求不要直接开写
  先确认目标、约束和验收标准
- 遇到信息不足时，说明你做了什么假设
  以及后来怎么验证假设

### 3. 到家的最少跳跃

LeetCode 1654

**题意**

位置从 0 出发，目标是 `x`
- 向前跳 `a`
- 向后跳 `b`
- 不能连续向后跳两次
- 不能落在 `forbidden` 上
- 求最少跳跃次数，无法到达返回 `-1`

**思路**

BFS

状态不能只有位置
因为「上一步是不是向后跳」会影响下一步能不能向后
所以状态是 `(位置, 上一步是否向后)`

每次从队列取出状态，尝试

- 向前跳 `pos + a`
- 如果上一步不是向后，再尝试向后跳 `pos - b`

用 `visited[pos][back]` 去重
第一次到达 `x` 时的步数就是最少步数

**边界**

- 起点 0 在 `forbidden` 中，直接返回 `-1`
- 位置不能小于 0
- 位置不能超过上界
  常用上界是 `max(x, max(forbidden)) + a + b`
  超过这个范围没有意义
- 同一个位置可能以不同 `back` 状态到达
  不能只用一个一维 `visited`
- 如果 `x` 本身在 `forbidden` 中，无法到达

**复杂度**

设上界为 `N`
时间 `O(N)`，空间 `O(N)`

**代码**

```cpp
int minimumJumps(vector<int>& forbidden, int a, int b, int x) {
    unordered_set<int> ban(forbidden.begin(), forbidden.end());
    if (ban.count(0)) return -1;

    int upper = x;
    for (int f : forbidden) upper = max(upper, f);
    upper += a + b;

    vector<vector<bool>> visited(upper + 1, vector<bool>(2, false));
    queue<tuple<int, int, int>> q;  // 位置, 上一步是否向后, 步数

    visited[0][0] = true;
    q.push({0, 0, 0});

    while (!q.empty()) {
        auto [pos, back, steps] = q.front();
        q.pop();

        if (pos == x) return steps;

        int forward = pos + a;
        if (forward <= upper && !ban.count(forward) && !visited[forward][0]) {
            visited[forward][0] = true;
            q.push({forward, 0, steps + 1});
        }

        if (!back) {
            int backward = pos - b;
            if (backward >= 0 && !ban.count(backward) &&
                !visited[backward][1]) {
                visited[backward][1] = true;
                q.push({backward, 1, steps + 1});
            }
        }
    }

    return -1;
}
```

**追问**

- 为什么 BFS 得到的是最少步数
  因为每条边代价都是 1，BFS 按层扩展
- 能不能用动态规划
  有「不能连续后退」的状态，且前后跳可能形成环
  用 BFS 更直接
- 上界怎么证明
  超过目标或最远障碍后再绕远没有收益
  取 `max(x, max(forbidden)) + a + b` 足够

### 4. 和为目标值且不重叠的非空子数组的最大数目

LeetCode 1546

**题意**

给定数组 `nums` 和目标值 `target`
选出尽可能多的非空子数组，使每个子数组的和都等于 `target`
子数组之间不能重叠
返回最大数目

**思路**

前缀和 + 贪心

从左到右扫描，维护当前前缀和 `sum`

- 如果 `sum - target` 在之前出现过
  说明存在一个以当前位置结尾、和为 `target` 的子数组
- 为了让后面的选择空间最大，直接选这个最早结束的区间
- 选择后清空哈希表，把 `sum` 重置为 0，相当于从下一个位置重新开始
- 否则把当前前缀和加入哈希表

这是区间调度里的经典贪心
在所有候选区间中，优先选结束最早的
不会让结果变差

**代码**

```cpp
int maxNonOverlapping(vector<int>& nums, int target) {
    unordered_set<int> seen;
    seen.insert(0);

    int sum = 0;
    int count = 0;

    for (int value : nums) {
        sum += value;

        if (seen.count(sum - target)) {
            ++count;
            seen.clear();
            seen.insert(0);
            sum = 0;
        } else {
            seen.insert(sum);
        }
    }

    return count;
}
```

**另一种写法**

用 `dp` 加「前缀和 → 最近下标」

```text
dp[i + 1] = max(dp[i], dp[last[sum - target] + 1] + 1)
```

`dp[i]` 表示前 `i` 个元素里的最大数目
这种写法不重置前缀和，更适合需要保留全局状态的变体

**边界**

- `target` 可能为负数，前缀和做法仍然成立
- 子数组必须非空
- 选择区间后要保证不重叠
  贪心重置就是为此服务的
- 如果有多个区间在同一位置结束，选哪一个不影响数量

**复杂度**

时间 `O(n)`，空间 `O(n)`
