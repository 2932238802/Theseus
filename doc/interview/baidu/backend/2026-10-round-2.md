## 题目

### 1. 点在有向线段的哪一侧

**题目**

给定平面上的三个点 A、B、C
从 A 走向 B，形成有向线段 AB
判断 C 在 AB 的左侧、右侧，还是恰好落在直线上

**思路**

用叉积判断方向

```text
AB × AC = (B - A) × (C - A)
        = (Bx - Ax) * (Cy - Ay) - (By - Ay) * (Cx - Ax)
```

- 结果大于 0：C 在 AB 左侧
- 结果小于 0：C 在 AB 右侧
- 结果等于 0：三点共线

前提是使用数学坐标系，x 向右、y 向上
屏幕坐标系 y 向下，左右方向会反过来

**边界与追问**

- 题目说的是「有向线段」还是「直线」要确认
  叉积只能判断在直线的哪一侧
  如果 C 在 AB 延长线上，仍然会得到左或右
- 判断 C 是否落在线段 AB 上，需要同时满足
  - 叉积为 0
  - C 在 AB 的包围盒内，或 `dot(AC, BC) <= 0`
- 坐标范围大时要防溢出
  32 位整数相乘可能溢出，使用 `long long`
  若坐标接近 `1e9` 以上，考虑 `__int128`
- 浮点坐标不要直接用 `== 0`
  用 `abs(cross) <= eps`，eps 按坐标量级选取

**代码**

```cpp
enum class Side { Left, Right, OnLine };

Side sideOfPoint(long long ax, long long ay,
                 long long bx, long long by,
                 long long cx, long long cy) {
    __int128 cross = ((__int128)bx - ax) * ((__int128)cy - ay)
                   - ((__int128)by - ay) * ((__int128)cx - ax);

    if (cross > 0) return Side::Left;
    if (cross < 0) return Side::Right;
    return Side::OnLine;
}
```

**可延伸的点**

- 凸包、极角排序、线段相交都会用到叉积
- 线段相交：两次跨立实验加共线特判
- 多边形面积：鞋带公式，本质也是叉积

### 2. 判断车辆坐标是否在多边形内部

**题目**

自动驾驶场景下，有一个区域（国家、省或自定义电子围栏）的边界线数据
边界线构成一个多边形
给定车辆当前坐标，判断点在多边形内部还是外部

**思路**

常用射线法（Ray Casting）

从待判断点向任意方向发一条射线
统计射线与多边形边的交点个数

- 交点数为奇数：点在多边形内部
- 交点数为偶数：点在多边形外部

实现时通常向右发射水平射线，只统计满足以下条件的边

```text
(a.y > p.y) != (b.y > p.y)
```

这样可以让水平边、顶点相交只被计算一次

交点横坐标

```text
x = a.x + (p.y - a.y) * (b.x - a.x) / (b.y - a.y)
```

若 `x > p.x`，说明射线与这条边相交，翻转内外状态

**必须先处理边界**

叉积为 0 且点落在边的包围盒内，直接返回「在边界上」
否则点在边上时，射线法可能得到内部或外部，结果不稳定

**工程上的追问**

- 经纬度不能直接当平面坐标
  小范围可以用等距投影或墨卡托投影近似
  跨经线、极地附近要做特殊处理
- 国界、省界通常是 GeoJSON
  可能有多个多边形、内环（湖、飞地）和孔洞
  需要分别判断：在外环内且不在任何内环内
- 边很多时先做包围盒预筛
  再用网格、R-tree 或空间索引缩小候选边
- 边界数据量很大时，可以把多边形预处理成瓦片或网格
  在线只做点查询
- 点在边界上的业务语义要定义清楚
  电子围栏通常把边界算作「内部」或单独返回「边界」
- 车辆坐标会有定位误差
  如果业务要求严格，需要结合精度半径判断「接近边界」的状态

**代码**

```cpp
struct Point { long double x, y; };

enum class Position { Inside, Outside, Boundary };

Position locate(const std::vector<Point>& poly, const Point& p) {
    bool inside = false;
    const size_t n = poly.size();

    for (size_t i = 0, j = n - 1; i < n; j = i++) {
        const Point& a = poly[j];
        const Point& b = poly[i];

        // 先判断点是否在边上
        long double cross = (b.x - a.x) * (p.y - a.y)
                          - (b.y - a.y) * (p.x - a.x);
        if (std::fabs(cross) <= 1e-12L &&
            std::min(a.x, b.x) <= p.x && p.x <= std::max(a.x, b.x) &&
            std::min(a.y, b.y) <= p.y && p.y <= std::max(a.y, b.y)) {
            return Position::Boundary;
        }

        // 水平射线只与跨越 p.y 的边相交
        if ((a.y > p.y) != (b.y > p.y)) {
            long double x = a.x + (p.y - a.y) * (b.x - a.x) / (b.y - a.y);
            if (x > p.x) inside = !inside;
        }
    }

    return inside ? Position::Inside : Position::Outside;
}
```

**另一个方向**

也可以使用环绕数（Winding Number）
它通过有符号角度或叉积累计判断点是否被多边形包围
对自相交多边形和方向的定义更敏感，但边界处理同样要先做

### 3. 两个链表相加

**题目**

```cpp
ListNode* addList(ListNode* l1, ListNode* l2);
```

两个链表表示两个非负整数
每个节点存储一位数字，按逆序存放
把两个数相加，返回同样形式的链表
需要考虑健壮性

**思路**

逐位相加，用一个变量保存进位

- 用哨兵节点简化头节点处理
- 同时遍历两个链表，短的补 0
- 每一位计算 `sum = carry + l1->val + l2->val`
- 当前位是 `sum % 10`，进位是 `sum / 10`
- 循环结束后如果还有进位，再补一个节点

时间复杂度 `O(max(m, n))`
返回值需要新链表，额外空间 `O(max(m, n))`

**健壮性**

- 任一链表为空
- 两个链表长度不同
- 最后一位产生进位，例如 `99 + 1 = 100`
- 节点值不一定是 0 到 9
  如果题目保证是十进制位，按 10 取模
  如果可能超过 9，要先明确语义，或改用更大的基数
- 负数
  单链表如果允许负号，需要先统一符号再处理
  面试时先确认输入约定
- 不修改原链表
  如果允许修改，可以直接复用节点；不允许则新建节点
- 内存释放
  返回的新链表由调用方负责释放
- 递归写法也可以，但链表很长时会爆栈

**代码**

```cpp
struct ListNode {
    int val;
    ListNode* next;
    ListNode(int x) : val(x), next(nullptr) {}
};

ListNode* addList(ListNode* l1, ListNode* l2) {
    ListNode dummy(0);
    ListNode* tail = &dummy;
    int carry = 0;

    while (l1 != nullptr || l2 != nullptr || carry != 0) {
        int sum = carry;
        if (l1 != nullptr) {
            sum += l1->val;
            l1 = l1->next;
        }
        if (l2 != nullptr) {
            sum += l2->val;
            l2 = l2->next;
        }

        carry = sum / 10;
        tail->next = new ListNode(sum % 10);
        tail = tail->next;
    }

    return dummy.next;
}
```

**追问**

- 如果链表是正序存放怎么办
  可以先用栈，或先反转链表，或递归到末尾再回溯
- 如果要求原地修改
  以较长的链表为基础，把结果写回节点，注意最后进位
- 如果数字非常大
  链表本身就是用来避免大整数溢出的，不要转成 `int` 或 `long long`
- 如果要支持任意进制
  把 10 换成对应基数即可

## 复盘

- 场景题要先确认题目边界
  例如「线段」还是「直线」，「边界算内还是外」
- 先说思路和复杂度，再写代码
  面试官更关心判断过程和边界覆盖
- 手撕题先处理空链表、长短不一、最后进位
  这三类情况覆盖后，代码基本就稳了
