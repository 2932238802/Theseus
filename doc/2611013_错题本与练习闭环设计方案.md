# 错题本与练习闭环设计方案

> 日期：2026-11-01
> 状态：v1 已实现
> 关联：`2610272_个人界面的完善.md`、`2611012_架构与性能收口.md`、`backend_api.md`

## 1. 目标

把首页「错题本」占位入口（原先只是跳转到题库的 `attempted` 筛选）换成独立功能：

- 自动聚合未通过的题，显示失败次数、最近一次状态与最近失败时间
- 支持难度、标签筛选，按最近失败或失败次数排序，分页浏览
- 已复习的题可以移出错题本，误操作可撤销
- 题目通过后自动移出；移出后如果又做错，自动回到错题本
- 首页「待复习」与错题本使用同一口径，移出后数字同步减少

## 2. 判定规则

一道题进入错题本需要同时满足：

- 当前用户在这道题上至少有一次已判定且未通过的提交（排队中与评测中不计）
- 当前用户在这道题上还没有 `accepted` 提交
- 题目已审核通过
- 没有被移出，或移出之后又出现了更新的失败提交

因此「通过」是离开错题本的唯一自动方式；手动移出只是暂时隐藏。

## 3. 数据模型

`0039_wrong_problem_dismissals.sql` 新增 `wrong_problem_dismissals`：

| 字段 | 说明 |
|---|---|
| `user_id` | 用户，删除用户时级联删除 |
| `problem_id` | 题目，删除题目时级联删除 |
| `dismissed_at` | 移出时间，重复移出时刷新 |
| 主键 | `(user_id, problem_id)` |

移出记录不删除历史失败提交，判定时比较 `dismissed_at` 与最近一次失败时间：只要之后出现新的失败提交，题目就重新出现在错题本里。

## 4. 接口

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| GET | `/api/profile/wrong-problems` | 登录用户 | 错题本列表，支持 `page`、`size`、`difficulty`、`tag`、`sort` |
| DELETE | `/api/profile/wrong-problems/{problem_id}` | 登录用户 | 移出错题本，返回 `{dismissed:true}` |
| POST | `/api/profile/wrong-problems/{problem_id}` | 登录用户 | 撤销移出，返回 `{dismissed:false}` |

列表项字段：

| 字段 | 说明 |
|---|---|
| `problem_id` / `title` / `difficulty` / `tags` / `acceptance_rate` | 题目基本信息 |
| `attempt_count` | 已判定的未通过提交次数 |
| `last_failed_at` / `last_status` / `last_language` | 最近一次未通过提交 |
| `last_test_cases_passed` / `last_total_test_cases` | 最近一次的用例通过情况 |

约束：

- `sort` 取 `recent`（默认，最近失败优先）或 `attempts`（失败次数优先）
- `size` 取值 1–50，默认 20
- 移出时题目必须确实在错题本中，否则返回 404「该题目不在错题本中」
- 撤销移出幂等，未移出过也返回成功

## 5. 前端实现

| 文件 | 变更 |
|---|---|
| `src/api/wrongProblems.ts` | 列表、移出与撤销请求，字段按后端结构映射 |
| `src/types/wrongProblem.ts` | 错题条目与分页结果类型 |
| `src/views/ProfileWrongProblemsPage.vue` | 难度/标签筛选、排序、列表、移出与撤销、分页与空状态 |
| `src/router/index.ts` | 新增 `/profile/wrong-problems` 路由 |
| `src/components/NavBar.vue` | 个人菜单新增「错题本」 |
| `src/views/ProfilePage.vue` | 个人界面不显示错题本入口，统一从个人菜单进入 |
| `src/views/IndexPage.vue` | 「待复习」统计与「错题本」快捷入口指向新页面 |

交互规则：

- 切换筛选或排序后回到第 1 页
- 移出后顶部出现「已移出《题目》 撤销」，撤销后重新加载当前页
- 移出当前页最后一条时自动回到上一页
- 空错题本显示空状态与题库入口
