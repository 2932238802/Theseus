# 题目笔记设计方案

> 日期：2026-10-31
> 状态：v1 已实现
> 关联：`2610314_题目题解与讨论区设计方案.md`、`backend_api.md`

## 1. 目标

参考力扣的题目笔记能力，为每道题提供仅本人可见的 Markdown 笔记：

- 在题目页「笔记」Tab 内直接编辑、预览与自动保存
- 每个用户、每道题只保留一份笔记，重复保存覆盖旧内容
- 个人中心新增「我的笔记」汇总页，按更新时间倒序查看并跳回题目
- 笔记不进入论坛、不公开、不参与搜索与排行榜

## 2. 数据模型

`0037_problem_notes.sql` 新增 `problem_notes`：

| 字段 | 说明 |
|---|---|
| `user_id` | 作者，指向 `users(id)`，删除用户时级联删除 |
| `problem_id` | 题目，指向 `problems(id)`，删除题目时级联删除 |
| `body_md` | Markdown 原文，去除首尾空白后为空时删除记录 |
| `created_at` | 首次创建时间 |
| `updated_at` | 最后保存时间，保存时刷新 |
| 主键 | `(user_id, problem_id)` |

索引 `(user_id, updated_at DESC)` 支撑个人笔记列表。

## 3. 接口

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| GET | `/api/problems/{id}/note` | 登录用户 | 返回 `{note:{body_md,updated_at}\|null}` |
| PUT | `/api/problems/{id}/note` | 登录用户 | 请求 `{"body_md":"..."}`，保存并返回同样的 `note` 结构 |
| GET | `/api/profile/notes?page=&size=` | 登录用户 | 返回当前用户的笔记摘要 `{total,page,size,notes:[{problem_id,title,difficulty,excerpt,updated_at}]}` |

约束：

- 题目必须已审核，否则返回 404「题目不存在」
- 笔记正文最长 32KB，超限返回 400「笔记内容过长」
- `body_md` 去除首尾空白后为空时删除笔记，返回 `note: null`
- 个人笔记列表只返回已审核题目，摘要截取前 160 字
- 所有接口都只操作当前登录用户自己的笔记，不接受他人 `user_id`

## 4. 前端实现

| 文件 | 变更 |
|---|---|
| `src/components/ProblemNotePanel.vue` | 笔记加载、编辑/预览、700ms 防抖自动保存、保存状态与失败重试 |
| `src/views/OjPage.vue` | 题目页新增「笔记」Tab，未登录时显示登录入口，竞赛答题页隐藏全部 Tab |
| `src/views/ProfileNotesPage.vue` | 「我的笔记」列表、分页与跳转题目 |
| `src/api/notes.ts`、`src/types/note.ts` | 笔记读写与列表类型 |
| `src/router/index.ts`、`src/components/NavBar.vue` | 新增 `/profile/notes` 与个人菜单入口 |
| `src/styles/problems.css` | 编辑器、预览、保存状态与空状态样式 |

自动保存规则：

- 输入停止约 700ms 后保存，保存请求按输入顺序串行执行
- 切换题目或离开页面时，若存在未保存内容会补发一次保存请求
- 保存失败显示「保存失败」和「重试」，不清空编辑内容

## 5. 边界

- 笔记只在题目页与个人笔记页出现，不进入论坛或公开搜索
- 题目被删除或用户注销时笔记级联删除，不做额外保留
- 本期不做图片上传、笔记导出、版本历史与公开分享
