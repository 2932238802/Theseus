# 教学数据导入导出

> 日期：2026-10-30
> 状态：已完成
> 关联：`doc/总体设计.md` §4.6、`doc/backend_api.md`「教学数据导入与导出」
> 接口：`POST /api/classes/{id}/import`、`GET /api/assignments/{id}/gradebook/export`

## 1. 目标与范围

补齐教学闭环中「名单进入」和「成绩带出」两段手工操作：

| 能力 | v1 行为 |
|---|---|
| 学生名单导入 | 教师上传或粘贴 CSV，按用户名/邮箱批量加入组织 |
| 导入结果 | 逐行返回新增或跳过原因，单行失败不影响其他行 |
| 成绩导出 | 教师从批改台导出当前作业成绩 CSV，Excel 可直接打开 |
| 成绩邮件 | 复用既有 `assignment_grades_published` 通知与邮件偏好，不新增渠道 |

明确不做：Excel（`.xlsx`）解析、导入邀请制（仍走现有的邀请接口）、跨作业汇总导出、统计报表导出、CSV 模板下载。

## 2. 导入流程

```text
教师选择 CSV 文件或粘贴文本
  → 前端读取为字符串，POST /api/classes/{id}/import {csv}
  → 后端校验大小与格式
  → 识别可选表头 username/email（支持“用户名/邮箱”）
  → 逐行查找用户（先用户名，再邮箱）
  → 校验角色、是否已是成员、是否文件内重复
  → 直接写入 class_members（复用单条添加成员的 upsert 语义）
  → 返回 added_count / skipped_count / rows
  → 前端刷新组织详情，展示跳过行
```

导入采用「直接加入」而不是「发送邀请」，与既有 `POST /api/classes/{id}/members` 保持一致：教师本来就可以按用户名或邮箱直接添加学生。邀请流程仍由「邀请学生」面板负责，两条路径不混用。

### 2.1 CSV 格式

```csv
username,email
alice,alice@example.com
bob,
carol,carol@example.com
```

- 表头可选；出现 `username`/`email`/`用户名`/`邮箱` 时按列取值，否则按行内非空单元格顺序尝试。
- 支持双引号包裹、字段内逗号与换行、`""` 转义、CRLF 与 UTF-8 BOM。
- 空行和以 `#` 开头的行忽略。
- 同一文件内按首个标识符去重，重复行标记 `duplicate`。

### 2.2 行状态

| `status` | 含义 | 是否计入 `added_count` |
|---|---|---|
| `added` | 已加入组织 | 是 |
| `already_member` | 已经是有效成员 | 否 |
| `not_found` | 用户名和邮箱都查不到 | 否 |
| `not_student` | 目标是教师或管理员 | 否 |
| `duplicate` | 文件内重复出现 | 否 |
| `invalid` | 该行没有用户名或邮箱 | 否 |

### 2.3 限制与错误

- 请求体 ≤1 MB（路由单独设置 `DefaultBodyLimit`），CSV 文本 ≤512 KB；
- 最多 500 名学生、10 列，单字段 ≤320 字符；
- 引号未闭合、列数或行数超限返回 400；
- 组织已归档返回 409；非 owner 教师返回 404（不暴露组织存在性）；
- 学生调用返回 403。

## 3. 成绩导出

`GET /api/assignments/{id}/gradebook/export` 复用批改台的计算结果 `compute_gradebook`，保证导出分数与页面一致，不重复实现计分逻辑。

列：

| 列 | 来源 |
|---|---|
| 用户名、邮箱 | `users` |
| 成员状态 | `active` → 正常，`removed` → 已移除 |
| 各题最终分 | `GradebookCell.final_score`，表头为 `题目名（N 分）` |
| 总分 | `GradebookStudent.total_score` |
| 整体评语 | `assignment_results.overall_feedback` |

CSV 细节：

- UTF-8 BOM（`\u{feff}`）开头，避免 Excel 打开中文乱码；
- 含逗号、双引号、换行或回车的字段加引号，内部 `"` 加倍；
- 行尾 `\n`；
- `Content-Disposition` 使用 ASCII 文件名 `assignment-{id}-grades.csv`，前端下载时再拼作业标题。

新增 `common::csv` 只负责解析，单元测试覆盖空行、注释、引号、转义、CRLF、BOM、未闭合引号与行数上限。

## 4. 权限

| 接口 | 权限 |
|---|---|
| `POST /api/classes/{id}/import` | `teacher` 且为组织 owner；管理员不可进入教学数据 |
| `GET /api/assignments/{id}/gradebook/export` | `teacher` 且为作业所属组织 owner |

学生和非 owner 教师无法导出成绩；学生也无法调用导入接口。

## 5. 前端

- `ClassDetailPage`：新增「批量导入学生」面板，支持选择 `.csv` 文件或直接粘贴；导入后展示新增人数与跳过行（行号、标识符、原因），并刷新成员列表。
- `GradebookPage`：头部新增「导出成绩」，按当前 `include_removed` 状态请求导出，浏览器直接下载，文件名使用作业标题。
- 未新增页面或路由。

## 6. 测试

- 单元测试：`common/csv.rs` 解析用例；`grade_service` 的 CSV 转义与 BOM/表头/分数用例。
- 冒烟：`backend-rust/scripts/smoke_import_export.sh`
  - 预置 1 名成员，再导入包含新增、已存在、文件内重复、不存在、教师账号的 CSV；
  - 校验 `added_count`、`skipped_count`、各状态数量与组织有效成员数；
  - 校验学生 403、非 owner 教师 404、未闭合引号 400；
  - 创建并发布作业、写入人工分后导出，校验 HTTP 200、`text/csv`、BOM、表头、学生行与分数；
  - 校验学生导出 403、非 owner 教师导出 404。

## 7. 已知限制与后续

- 只支持 CSV，不支持 `.xlsx`；
- 导入为直接加入，学生不会收到「已加入组织」通知，与单条添加成员一致；
- 成绩导出只含最终分，不含每次提交、迟交扣分明细与策略审计；
- 未提供跨作业成绩汇总、统计报表导出和模板下载；
- 名单与成绩文件均在前端转成文本/Blob 传输，暂未接入对象存储或异步导出任务。
